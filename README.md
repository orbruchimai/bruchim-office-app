# משרד ברוכים - אפליקציית ניהול (PWA, שלד בהקמה)

שלד ראשוני של אפליקציית הניהול לעסק, להתקנה בטלפון מ-Chrome.

**האפליקציה:** https://orbruchimai.github.io/bruchim-office-app/

**האפיון (טיוטה):** [SPEC.md](SPEC.md)

## מה יש כרגע

שלד ממשק בלבד: מסך בית וארבעה מסכי פלייסהולדר - פתיחת תיק חדש, ניתוח דוח קיים, סטטוס לקוחות וכתיבת דוח.
אין כאן מידע עסקי, נתוני לקוחות או שמירת מידע. התחברות ובסיס נתונים מאובטח יגיעו בהמשך.

## איך מתקינים

פותחים את הקישור ב-Chrome בטלפון > תפריט (שלוש נקודות) > "התקנת אפליקציה" / "הוספה למסך הבית".

הלוגו נלקח מהאתר bruchim.com. המיפוי העסקי המלא בריפו הפרטי parents-business-flow.
